# A tune line is its collection path; each line below it is "offset old new" in
# hex, offsets into the .sid file, anything after the third value is a comment.
# A tune's patches apply only when every old byte matches, otherwise the file
# loads untouched, so an entry retires itself once HVSC ships the fixed file.
# Song lengths after the tune path ("/path/Tune.sid 1:32", one time per
# subtune) replace the HVSC's lengths for the tune; they cannot retire
# themselves, delete the block by hand once the HVSC carries the fix.
